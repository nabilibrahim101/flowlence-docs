# Part 1 · Getting Started

Welcome! In this part you will understand **what you're about to build and why**, meet the hardware in your Flowlence IoT Kit, install Flowlence Code, and run your very first program on the ESP32.

By the end of Part 1 you will:

- Understand what IoT and a Smart City are, and how they connect to this competition
- Know what's inside your kit
- Have Flowlence Code installed and opened on your computer
- Have made an LED on your ESP32 blink using blocks

## Lessons in this part

1. [What is IoT & a Smart City?](what-is-iot.md)
2. [Meet Your Kit](meet-your-kit.md)
3. [Install Flowlence Code](install.md)
4. [Tour the Interface](interface.md)
5. [Your First Program](first-program.md)

!!! tip "New to programming?"
    Don't worry — Flowlence Code is designed for beginners. You'll drag and snap colorful blocks together, and the program writes itself. No typing required to get started.
